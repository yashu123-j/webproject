🎮 Tic-Tac-Toe
A simple, interactive web-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

🧩 Overview
This is a classic two-player Tic-Tac-Toe game. The interface is clean and intuitive, and the game logic includes win/draw detection and instant board resets.

🚀 Getting Started
✅ Requirements
A modern web browser (Chrome, Firefox, Edge, etc.)
☁️ Deploy on Vercel
To deploy this project on Vercel:

Fork or clone this repository.
Login to your Vercel account (or sign up).
Click “New Project” and import your GitHub repo.
Choose the project — no build settings are needed (static site).
Upload the Environment Variables.
Click “Deploy” — your game will be live in seconds!
🕹️ How to Play
Player X goes first.
Click on an empty box to place your mark.
The game will automatically detect:
A win (3 in a row/column/diagonal)
A draw (no moves left)
Refresh the page or click the reset button to play again.
